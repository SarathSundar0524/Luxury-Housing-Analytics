# Luxury Housing Analytics – Bangalore

## Project Overview
This project analyzes luxury housing transactions in Bangalore to understand buyer behavior, pricing trends, and conversion efficiency across micro-markets. The objective is to provide business-ready insights through SQL analysis and a single master Power BI dashboard.

## Key Objectives
- Analyze transaction patterns in luxury real estate
- Study conversion rates across micro-markets and amenity levels
- Compare buyer segments (NRI vs Local)
- Identify high-performing locations and projects
- Present insights in a clean, decision-focused dashboard

## Tech Stack
- SQL (PostgreSQL-style queries)
- Power BI
- Excel / CSV datasets

## Dataset Summary
Key columns used:
- Micro_Market
- Project_Name
- Ticket_Price_Cr
- Unit_Size_Sqft
- Amenity_Score
- Connectivity_Score
- Buyer_Type
- Sales_Channel
- Possession_Status
- Booking_Flag

## Analysis Performed
- Booking conversion rate analysis
- Amenity bucket vs conversion study
- Micro-market performance comparison
- Buyer segment analysis (NRI vs Local)
- Price per sqft and ticket size trends
- Geographic distribution using map visuals

## Dashboard
The Power BI report contains:
- One master dashboard page
- KPI cards for bookings, conversion rate, and revenue
- Micro-market comparison visuals
- Amenity and connectivity impact analysis
- Interactive filters for business users
